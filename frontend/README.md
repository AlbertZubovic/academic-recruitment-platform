TeachTeam (TT) – Assignment 1 Prototype
This repository contains the front-end prototype for the TeachTeam (TT) web system, developed using React with TypeScript for Assignment 1 of the Full Stack Development course at RMIT.

About the Project
TeachTeam is a system for managing the selection and hiring of casual tutors for School of Computing Technologies courses. This prototype focuses on building the client-side UI using React + Chakra UI, leveraging localStorage for temporary data storage.

Key Features Implemented:

Sign-in with validation

Tutor application form

Lecturer dashboard with applicant ranking, selection, and commenting

Visual representations of applicant selections

Fully responsive and custom-styled UI

Getting Started
To run the project locally:

Install dependencies:

bash
npm install

Start the development server:

bash
npm run dev

Open your browser and go to:
http://localhost:3000

Tech Stack
React (TypeScript)

Chakra UI (for styling)

HTML5 localStorage (data persistence)

Recharts (data visualisation)
